# 设计账本（design-ledger）

按项目分文件的追加式更新日志（真值层）与推算看板（呈现层）。

## 规则

- **插件只建立规则**：真实文件存于项目文件夹（`projectsRoot` 配置的根目录下 `logs/` 与 `boards/` 子目录），插件自身不存数据
- **日志=真值**：append-only，只追加不删改；每条记录含时间/变更/依据/位置/状态
- **看板=推理层**：由日志推算生成，内容为当前生效状态汇总；推错可依据日志重算
- **按项目分文件**：每项目一对文件 `logs/<项目>.log.md` + `boards/<项目>.board.md`，避免单文件超限

## 工具

| 工具 | 用途 |
|---|---|
| `ledger_append` | 追加一条主人要求/设计变更到项目日志 |
| `ledger_board` | 依据日志推理生成/更新项目看板 |
| `ledger_read` | 读取项目日志或看板全文 |

## 配置

`projectsRoot`：项目文件根目录（默认 `G:/program/飞书cli/docs`）。
